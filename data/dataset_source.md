
## Dataset Description
This transactional dataset tracks order, product, customer, and regional data, enabling multi-dimensional analysis of sales performance and trends.

Key columns include:

- Order ID
- Order Date
- Product ID
- Product Name
- Market
- Region
- Category
- Sub-Category
- Sales
- Profit

---

## Data Source
The dataset used in this project is publicly available.

Dataset: Superstore Sales Dataset
Source: Kaggle

You can download the dataset from the original source:

https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting/data
